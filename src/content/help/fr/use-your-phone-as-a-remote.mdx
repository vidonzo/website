Tout appareil équipé de Vidonzo peut piloter le téléviseur équipé de Vidonzo,
via votre réseau local. Parcourir une liste de vingt mille chaînes à la croix
directionnelle est désagréable ; le faire sur le téléphone que vous avez déjà en
main ne l'est pas.

## Ce qu'il vous faut

- Vidonzo installé à la fois sur le téléviseur et sur l'appareil qui commande
- Les deux appareils sur **le même réseau local**

## Association

1. Sur le téléviseur, ouvrez **Réglages → Télécommande**. Un QR code et un code
   court s'affichent.
2. Sur le téléphone, ouvrez **Télécommande**. Les téléviseurs proches
   apparaissent automatiquement — Vidonzo s'annonce en mDNS, il n'y a donc rien
   à taper.
3. Choisissez le téléviseur, ou scannez le QR code si vous préférez procéder
   explicitement.
4. Confirmez sur le téléviseur.

L'association est mémorisée : les fois suivantes, la connexion est immédiate.

## Ce que vous pouvez faire depuis le téléphone

- Parcourir et rechercher dans toute la bibliothèque du téléviseur
- Lancer la lecture d'une seule pression
- Mettre la suite en file d'attente sans interrompre ce qui est à l'écran
- Ajouter et retirer des favoris
- Utiliser le pavé tactile comme pointeur et le clavier du téléphone pour la
  saisie

## Depuis une montre connectée

Une montre associée offre les commandes de lecture de base — lecture, pause,
saut et volume — ce qui suffit quand le téléphone est dans une autre pièce.

## Si le téléviseur n'est pas détecté

- Vérifiez que les deux appareils sont bien sur le même réseau, et non l'un en
  Wi-Fi et l'autre sur un réseau invité.
- Certaines box activent le **client isolation** entre appareils sans fil ;
  désactivez-le, ou reliez le téléviseur en Ethernet.
- Scanner le QR code contourne entièrement la détection, et cela vaut la peine
  d'être essayé en premier.
