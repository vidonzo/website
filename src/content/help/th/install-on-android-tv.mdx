Vidonzo มีเวอร์ชัน Android TV โดยเฉพาะ ที่ใช้รีโมตเดินได้ครบทุกส่วน
เวอร์ชันนี้แจกจ่ายเป็น APK โดยตรง จึงต้องติดตั้งด้วยการไซด์โหลด

## อนุญาตการติดตั้งจากแหล่งที่ไม่รู้จัก

บนโทรทัศน์ของคุณ ให้เปิด
**การตั้งค่า → ความปลอดภัยและข้อจำกัด → แหล่งที่ไม่รู้จัก**
แล้วเปิดสิทธิ์ให้แอปจัดการไฟล์หรือเบราว์เซอร์ที่คุณกำลังจะใช้
ผู้ผลิตแต่ละรายเรียกมันไม่เหมือนกัน ให้มองหาคำว่า “แหล่งที่ไม่รู้จัก”
หรือ “ติดตั้งแอปที่ไม่รู้จัก”

## ทางที่หนึ่ง — แอปดาวน์โหลด

1. ติดตั้งแอปดาวน์โหลดจาก Play Store บนโทรทัศน์ของคุณ
2. กรอกที่อยู่ APK จาก[หน้าดาวน์โหลด](/th/download/)
3. ยืนยันการติดตั้งเมื่อระบบถาม

## ทางที่สอง — แฟลชไดรฟ์ USB

1. ดาวน์โหลด APK สำหรับ Android TV ลงคอมพิวเตอร์
2. คัดลอกมันลงแฟลชไดรฟ์ USB แล้วเสียบแฟลชไดรฟ์เข้ากับโทรทัศน์
3. เปิดมันด้วยแอปจัดการไฟล์ แล้วยืนยันการติดตั้ง

## ทางที่สาม — จากอุปกรณ์ Android อีกเครื่อง

ใช้ ADB ผ่านเครือข่าย จากคอมพิวเตอร์ที่อยู่ในเครือข่ายเดียวกัน

```
adb connect <tv-ip>:5555
adb install vidonzo-android-tv-universal-latest.apk
```

## การลงชื่อเข้าใช้บนโทรทัศน์

การพิมพ์อีเมลกับรหัสผ่านด้วยรีโมตนั้นทรมาน
การลงชื่อเข้าใช้บนทีวีจึงใช้รหัสหกหลักที่ส่งไปยังอีเมลของคุณแทน
จากนั้นเพลย์ลิสต์ของคุณจะแสดงเป็นสถานะล็อกอยู่
จนกว่าคุณจะอนุมัติเครื่องทีวีนั้นจากมือถือที่ลงชื่อเข้าใช้ไว้แล้ว

## การอัปเดต

เวอร์ชันที่ไซด์โหลดมาจะไม่อัปเดตตัวเอง ให้ติดตั้ง APK ตัวใหม่ทับตัวเก่าได้เลย
เพลย์ลิสต์ รายการโปรด และความคืบหน้าการดูของคุณยังอยู่ครบ
