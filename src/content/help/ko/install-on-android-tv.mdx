Vidonzo에는 리모컨만으로 끝까지 다룰 수 있는 Android TV 전용 빌드가 있습니다. 이
빌드는 APK로 직접 배포되므로 사이드로딩으로 설치합니다.

## 출처를 알 수 없는 앱 설치 허용하기

텔레비전에서 **설정 → 보안 및 제한 → 출처를 알 수 없는 앱**을 열고, 앞으로 쓸
파일 관리자나 브라우저를 켜 줍니다. 제조사마다 표현이 달라서,
「출처를 알 수 없는 앱」이나 「알 수 없는 앱 설치」에 해당하는 항목을 찾으면
됩니다.

## 방법 1 — 다운로더 앱

1. 텔레비전의 Play Store에서 다운로더 앱을 설치합니다.
2. [다운로드 페이지](/ko/download/)에 있는 APK 주소를 입력합니다.
3. 설치할지 물으면 승인합니다.

## 방법 2 — USB 드라이브

1. 컴퓨터에서 Android TV용 APK를 다운로드합니다.
2. USB 드라이브에 복사하고 그 드라이브를 텔레비전에 꽂습니다.
3. 파일 관리자로 열어 설치를 승인합니다.

## 방법 3 — 다른 Android 기기에서

같은 네트워크에 있는 컴퓨터에서, 네트워크를 통한 ADB로.

```
adb connect <tv-ip>:5555
adb install vidonzo-android-tv-universal-latest.apk
```

## 텔레비전에서 로그인하기

리모컨으로 이메일과 비밀번호를 입력하는 일은 괴로우므로, TV 로그인은 대신
이메일로 오는 여섯 자리 코드를 씁니다. 재생목록은 처음에 잠긴 상태로 보이다가,
이미 로그인해 둔 휴대폰에서 그 TV를 승인하면 열립니다.

## 업데이트

사이드로드한 빌드는 스스로 업데이트되지 않습니다. 새 APK를 예전 것 위에 그대로
설치하면 됩니다. 재생목록과 즐겨찾기, 시청 위치는 그대로 남습니다.
