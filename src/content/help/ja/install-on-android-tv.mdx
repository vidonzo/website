VidonzoにはAndroid TV専用の版があり、リモコンだけで隅々まで操作できます。この版
はAPKとして直接配布されるので、インストールはサイドロードで行います。

## 提供元不明のアプリを許可する

テレビで**設定 → セキュリティと制限 → 提供元不明のアプリ**を開き、これから使う
ファイル管理アプリまたはブラウザを有効にします。メーカーによって言い回しが違う
ので、「提供元不明のアプリ」や「不明なアプリのインストール」にあたる項目を探して
ください。

## 方法1——ダウンローダーアプリ

1. テレビのPlay Storeからダウンローダーアプリをインストールします。
2. [ダウンロードページ](/ja/download/)にあるAPKのアドレスを入力します。
3. 確認を求められたら、インストールを承認します。

## 方法2——USBメモリ

1. Android TV用のAPKをパソコンにダウンロードします。
2. USBメモリにコピーし、そのUSBメモリをテレビに挿します。
3. ファイル管理アプリから開いて、インストールを承認します。

## 方法3——別のAndroid端末から

同じネットワーク上のパソコンから、ネットワーク越しのADBで。

```
adb connect <tv-ip>:5555
adb install vidonzo-android-tv-universal-latest.apk
```

## テレビでサインインする

リモコンでメールアドレスとパスワードを打つのは苦行なので、テレビでのサインインに
は、代わりにメールへ届く六桁のコードを使います。プレイリストは最初ロックされた
状態で表示され、すでにサインインしているスマートフォンからそのテレビを承認すると
開きます。

## 更新

サイドロードした版は自分では更新されません。新しいAPKを古いものに上書き
インストールしてください。プレイリスト、お気に入り、視聴の続きは保持されます。
