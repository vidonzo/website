**ลิงก์ M3U8 คือที่อยู่ของไฟล์ข้อความเล็ก ๆ ในรูปแบบ M3U ที่บันทึกเป็น UTF-8**
ข้างในไม่เคยมีตัววิดีโอ สิ่งที่อยู่ข้างในเป็นตัวบอกว่าคุณถืออะไรอยู่
และในทางปฏิบัติมันเป็นได้หนึ่งในสองอย่างที่ต่างกันมาก

- **สตรีม HLS** คือช่องเดียวหรือวิดีโอเดียว
  ที่เขียนเป็นรายการของวิดีโอชิ้นสั้น ๆ ให้เครื่องเล่นดึงมาทีละชิ้น
  นี่คือความหมายของนามสกุลนี้ในเว็บส่วนใหญ่
- **เพลย์ลิสต์ช่อง** คือชื่อช่องหลายร้อยช่องพร้อมที่อยู่สตรีม
  เหมือนไฟล์ `.m3u` ทุกอย่าง เพียงแต่ข้อความเป็น UTF-8
  [M3U กับ M3U8 ต่างกันอย่างไร](/th/blog/m3u-กับ-m3u8-ต่างกันอย่างไร/)
  อธิบายด้านนี้ไว้แล้ว

สองแบบนี้หน้าตาเหมือนกันเป๊ะในช่องที่อยู่ แต่พฤติกรรมไม่เหมือนกันเลย
งานแรกจึงเป็นการแยกให้ออกว่าเป็นแบบไหน

## ดูอย่างไรว่าเป็นแบบไหน

เปิดลิงก์ในเบราว์เซอร์ หรือบันทึกไฟล์ไว้แล้วเปิดด้วยโปรแกรมแก้ไขข้อความ
แค่ไม่กี่บรรทัดแรกก็รู้แล้ว

**เพลย์ลิสต์** อ่านแล้วเหมือนสมุดรายชื่อ คือชื่อหนึ่งบรรทัด ที่อยู่หนึ่งบรรทัด
วนไปเรื่อย ๆ

```
#EXTM3U
#EXTINF:-1 tvg-id="one.example" group-title="ข่าว",Channel One
http://example.com/live/one.m3u8
#EXTINF:-1 tvg-id="two.example" group-title="ภาพยนตร์",Channel Two
http://example.com/live/two.m3u8
```

**สตรีม HLS** อ่านแล้วเหมือนตารางเวลา อาจเป็นรายการระดับคุณภาพที่มีให้เลือก

```
#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=2500000,RESOLUTION=1280x720
720p/index.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=6000000,RESOLUTION=1920x1080
1080p/index.m3u8
```

หรือเป็นรายการชิ้นวิดีโอเอง

```
#EXTM3U
#EXT-X-TARGETDURATION:6
#EXT-X-MEDIA-SEQUENCE:48213
#EXTINF:6.0,
segment48213.ts
#EXTINF:6.0,
segment48214.ts
```

มีชื่อช่องและ `group-title` แปลว่าเพลย์ลิสต์
มีบรรทัด `#EXT-X-` แปลว่าสตรีม

## HLS เล่นอย่างไรจริง ๆ

HLS ย่อมาจาก HTTP Live Streaming
เป็นวิธีส่งวิดีโอทางอินเทอร์เน็ตที่ใช้กันแพร่หลายที่สุด
และไฟล์ `.m3u8` ก็คือสารบัญของมัน

ไฟล์แรกเรียกว่า **master playlist** ไล่รายการเดียวกันไว้หลายระดับคุณภาพ
แต่ละระดับบอกแบนด์วิดท์ที่ต้องใช้ เครื่องเล่นเลือกหนึ่งระดับแล้วเปิด
**media playlist** ของระดับนั้น ซึ่งระบุชิ้นวิดีโอไม่กี่ชิ้นถัดไป ชิ้นละไม่กี่วินาที
เครื่องเล่นดึงชิ้นเหล่านั้นมาเล่น แล้วกลับไปอ่าน media playlist อีกรอบเพื่อหาชิ้นต่อไป
สำหรับช่องสด รายการนี้เลื่อนไปข้างหน้าไม่หยุด
สำหรับภาพยนตร์ มันจบด้วยแท็กปิดท้าย และเครื่องเล่นรู้ความยาวทั้งเรื่อง

ส่วนที่ฉลาดคือเครื่องเล่นสลับระดับคุณภาพระหว่างชิ้นได้
พอเน็ตตก มันลดลงไปใช้เวอร์ชันที่เบากว่าแทนที่จะหยุดค้าง
แล้วค่อยขยับกลับขึ้นเมื่อเน็ตมีที่ว่างพอ
Vidonzo เริ่มช่องสดที่เวอร์ชันเบาที่สุดเพื่อให้ภาพขึ้นเร็ว แล้วขยับขึ้นเองโดยอัตโนมัติ
ถ้าอยากรู้ว่า HLS ต่างจากคู่แข่งอย่างไร ดูได้ใน
[บทอธิบายโพรโทคอลสตรีมมิง](/th/blog/hls-dash-rtsp-โปรโตคอลสตรีมมิง/)

## เปิดเล่นลิงก์ M3U8 อย่างไร

**ถ้าเป็นเพลย์ลิสต์** ที่ของมันคือเครื่องเล่น IPTV
ซึ่งจะแปลงมันเป็นช่อง หมวดหมู่ และผังรายการ
ใน Vidonzo ให้เลือก **เพิ่มบริการ → ลิงก์ M3U**
แล้ววางลงในช่อง **URL เพลย์ลิสต์ M3U/M3U8**
ถ้าเพลย์ลิสต์มาเป็นไฟล์ แท็บ **ไฟล์ M3U** จะเปิดมันจากเครื่องของคุณ

**ถ้าเป็นสตรีมเดียว** มีสามทางที่ตรงไปตรงมา

1. **VLC** เลือก *Media → Open Network Stream* (บน Mac คือ *File → Open
   Network*) วางลิงก์ แล้วกดเล่น VLC เก่งเรื่องนี้เป็นพิเศษ ส่วน
   [จุดที่มันเริ่มไม่พอ](/th/blog/vlc-เป็น-เครื่องเล่น-iptv-ได้ไหม/)
   เป็นอีกคำถามหนึ่ง
2. **Safari** เบราว์เซอร์ของ Apple เล่น HLS ได้ในตัว
   ลิงก์ `.m3u8` ตรง ๆ จึงมักเปิดขึ้นมาเป็นวิดีโอได้ทันที
   เบราว์เซอร์อื่นรองรับไม่เท่ากัน
   และหลายตัวเล่นได้เฉพาะในหน้าเว็บที่ฝังตัวเล่น HLS ไว้
3. **ห่อมันไว้ในเพลย์ลิสต์** เครื่องเล่น IPTV ต้องการรายการ
   และรายการที่มีหนึ่งรายการก็ยังเป็นรายการ
   บันทึกสามบรรทัดนี้ลงไฟล์ข้อความชื่อ `stream.m3u`
   โดยใส่ชื่อและที่อยู่ของคุณเอง

   ```
   #EXTM3U
   #EXTINF:-1,สตรีมของฉัน
   https://example.com/live/index.m3u8
   ```

   Vidonzo อ่านไฟล์นี้ผ่าน **ไฟล์ M3U** เหมือนเพลย์ลิสต์อื่นทุกอย่าง
   แล้วสตรีมนั้นก็จะอยู่ในคลังของคุณพร้อมชื่อ ข้าง ๆ ช่องอื่น ๆ

## ทำไมลิงก์ M3U8 ถึงใช้ไม่ได้

ลิงก์ที่เมื่อวานยังเล่นได้ แต่วันนี้ไม่ได้ ส่วนใหญ่เป็นหนึ่งในข้อเหล่านี้

- **มันมีวันหมดอายุฝังมาในตัว** ที่อยู่สตรีมหลายแห่งพกโทเค็นหรือลายเซ็น
  ไว้ในส่วนหลังเครื่องหมาย `?` เช่น `token=` `expires=` `sig=`
  ซึ่งใช้ได้แค่เซสชันเดียวหรือไม่กี่ชั่วโมง
  จากนั้นเซิร์ฟเวอร์จะปฏิเสธด้วยรหัส 403
  เครื่องเล่นของคุณไม่ได้ผิดอะไร กุญแจแค่หมดอายุไปเท่านั้น
- **มันใช้ได้เฉพาะที่ที่มันมา** เซิร์ฟเวอร์บางแห่งตรวจว่าแอปหรือหน้าเว็บไหนกำลังขอ
  แล้วปฏิเสธที่เหลือทั้งหมด
- **ชิ้นวิดีโอเลื่อนผ่านไปแล้ว** media playlist ของช่องสดระบุแค่ไม่กี่ชิ้นล่าสุด
  สำเนาที่บันทึกเป็นไฟล์ไว้จะเก่าภายในไม่กี่วินาที
- **สตรีมจบไปแล้วหรือย้ายที่** รหัส 404 แปลว่าที่อยู่นั้นไม่มีอยู่แล้ว

ถ้าเพลย์ลิสต์ที่เต็มไปด้วยช่อง `.m3u8` โหลดขึ้นแต่ไม่มีช่องไหนเล่นได้
ตัวการแทบไม่เคยเป็นนามสกุล แต่เป็นที่อยู่ข้างใน
และถ้าสตรีมเริ่มเล่นแล้วดับไปหลังไม่กี่วินาที
[นั่นคือการหลุดการเชื่อมต่อ ไม่ใช่การบัฟเฟอร์](/th/blog/สตรีม-หยุด-หลัง-ไม่กี่วินาที/)
ซึ่งมีสาเหตุของมันเอง

## สรุปสั้น ๆ

`.m3u8` คือสารบัญ ไม่เคยเป็นตัววิดีโอ
มีชื่อช่องข้างในแปลว่าเพลย์ลิสต์ ให้ส่งเข้าเครื่องเล่น
มีบรรทัด `#EXT-X-` แปลว่าสตรีม HLS เดี่ยว ให้เปิดใน VLC หรือ Safari
หรือห่อไว้ในเพลย์ลิสต์บรรทัดเดียว
และถ้าเคยใช้ได้แต่ตอนนี้ใช้ไม่ได้ ให้ดูวันหมดอายุในที่อยู่ก่อนไปดูที่อื่น
