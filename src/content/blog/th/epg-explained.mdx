ตารางที่บอกว่าตอนนี้กำลังฉายอะไร ต่อไปคืออะไร และเมื่อชั่วโมงที่แล้วฉายอะไร
เรียกว่า **EPG** ย่อมาจากผังรายการอิเล็กทรอนิกส์
บนกล่องรับสัญญาณดาวเทียม มันมาพร้อมกับสัญญาณออกอากาศ
ในเครื่องเล่น IPTV มันไม่ได้มาแบบนั้น
และความต่างข้อนี้อธิบายเรื่องแปลก ๆ เกือบทุกเรื่องที่ผังรายการเคยทำ

## มันเป็นไฟล์ที่สอง ไม่ใช่ส่วนหนึ่งของรายการช่อง

รายการช่องของคุณบอกว่า *สตรีมอยู่ที่ไหน*
ส่วน EPG บอกว่า *มีอะไรฉายอยู่บนสตรีมเหล่านั้น และฉายเมื่อไร*
ทั้งสองเป็นคนละเอกสารกัน ถูกดึงมาแยกกัน และอัปเดตคนละรอบ

รูปแบบที่ใช้กันคือ **XMLTV** เป็นไฟล์ XML ที่ไล่รายชื่อช่องก่อน
แล้วตามด้วยรายการที่ฉาย โดยแต่ละรายการมีการอ้างถึงช่อง เวลาเริ่ม เวลาจบ
ชื่อรายการ และมักมีคำอธิบายด้วย
ผังรายการที่ครอบคลุมช่องไม่กี่ร้อยช่องเป็นเวลาหนึ่งสัปดาห์คือไฟล์ขนาดใหญ่
ระดับหลายสิบเมกะไบต์ถือเป็นเรื่องปกติ
นั่นคือเหตุผลที่เครื่องเล่นดึงมันมาเบื้องหลัง
แทนที่จะดึงตอนที่คุณกดปุ่มเปิดผังรายการ

ถ้าคุณใช้ [Xtream Codes](/th/blog/xtream-codes-หรือ-m3u/)
ผังรายการมักตามมาให้เองอัตโนมัติ เพราะ API เปิดให้เข้าถึงมันอยู่แล้ว
และเครื่องเล่นเก็บมาให้โดยที่คุณไม่ต้องตั้งค่าอะไร
ส่วนกับ M3U ธรรมดา คุณมักต้องใส่ URL ของ EPG เอง
เพราะไฟล์เพลย์ลิสต์ไม่มีที่ให้ใส่มันไว้

## รายการหนึ่งหาช่องของตัวเองเจอได้อย่างไร

ตรงนี้คือจุดที่ผังรายการพัง และเหตุผลก็ไม่มีอะไรหวือหวา
คือไฟล์สองไฟล์ต้องเรียกชื่อให้ตรงกัน

แต่ละรายการในผังถูกกำกับด้วยรหัสประจำช่อง
และแต่ละช่องในเพลย์ลิสต์ของคุณก็พกรหัสแบบนั้นได้เหมือนกัน
ในแอตทริบิวต์ `tvg-id` เครื่องเล่นเอาสองอย่างนี้มาจับคู่กัน
เมื่อตรงกัน คุณก็ได้ตารางรายการ
เมื่อไม่ตรง คุณก็ได้ช่องที่เล่นได้ดีทุกอย่าง แต่ไม่แสดงอะไรเลยในผังรายการ

นั่นคือข้อร้องเรียนเรื่อง EPG ที่พบบ่อยที่สุด
และแทบไม่เคยเป็นเรื่องของเครื่องเล่น
`Channel One HD` ในเพลย์ลิสต์ กับ `channel.one.hd` ในผังรายการ
เป็นข้อความคนละชุดกัน และไม่มีอะไรเชื่อมมันเข้าหากันได้
นอกจากการแก้ที่ฝั่งผู้ให้บริการ หรือการจับคู่ด้วยมือ

## เขตเวลา ความผิดพลาดคลาสสิกอีกข้อหนึ่ง

ค่าเวลาใน XMLTV พกค่าชดเชยจาก UTC มาด้วย เช่น `20260729180000 +0300`
เมื่อไฟล์ของผู้ให้บริการไม่ใส่ค่าชดเชยนั้น หรือใส่ค่าที่ไม่ตรงกับความจริง
ผังรายการทั้งผังจะเลื่อนไป คือทุกอย่างถูกหมด
เพียงแต่คลาดจากความจริงไปไม่กี่ชั่วโมง

ถ้าผังรายการของคุณเลื่อนไปเท่ากันทั้งหมดเป็นจำนวนชั่วโมงเต็ม
นั่นคือสิ่งที่เกิดขึ้น และเป็นเรื่องที่ผู้ให้บริการต้องแก้ ไม่ใช่การตั้งค่าในอุปกรณ์
ถ้าเลื่อนแค่บางช่อง
แปลว่าช่องเหล่านั้นถูกดึงมาจากแหล่งผังรายการคนละแหล่งกับช่องที่เหลือ

## ผังรายการที่ดีให้อะไรคุณบ้าง

เมื่อจับคู่กันได้แล้ว EPG จะเลิกเป็นแค่ของประดับ

- **กำลังฉายและฉายต่อไป** เพื่อให้คุณเห็นว่ากำลังเข้ามาดูกลางเรื่องอะไรอยู่
- **ตารางที่เลื่อนไปดูล่วงหน้าได้** ซึ่งเป็นวิธีเดียวที่สบายพอ
  สำหรับวางแผนช่วงค่ำข้ามช่องหลายร้อยช่อง
- **การแจ้งเตือน** ในเครื่องเล่นที่มีให้
- **การค้นหาที่ดีขึ้น** เพราะคุณค้นหาตัวรายการได้ ไม่ใช่ค้นได้แค่ชื่อช่อง
- **การดูย้อนหลัง** ในกรณีที่ผู้ให้บริการรองรับ
  ผังรายการคือสิ่งที่ทำให้เครื่องเล่นมีอะไรให้ร้องขอไป

## เมื่อผังรายการว่างเปล่า

ไล่ไปตามลำดับ

1. **รอก่อน** หลังเพิ่มเพลย์ลิสต์ การดึง EPG ครั้งแรกใช้เวลาสักพัก
   ในไม่กี่นาทีแรกยังไม่มีอะไรผิดปกติ
2. **ดูก่อนว่ามีผังรายการอยู่จริงไหม** ถ้าแหล่งข้อมูลเป็น M3U
   แล้วคุณไม่เคยได้ URL ของ EPG มาเลย ก็ไม่มีอะไรให้แสดง
   ให้ขอจากผู้ให้บริการ
3. **เทียบช่องเดียวกับทุกช่อง** ว่างอยู่ไม่กี่ช่องคือรหัสประจำช่องไม่ตรงกัน
   ว่างทุกช่องคือปัญหาการดึงไฟล์
4. **สั่งรีเฟรชผังรายการ** ถ้าเครื่องเล่นมีให้
   ซึ่งจะดาวน์โหลดใหม่ ไม่ใช่อ่านซ้ำจากแคช
5. **ดูช่วงเวลาด้วย** ผู้ให้บริการบางรายเผยแพร่ช่วงเวลาแคบ ๆ
   คือแค่วันนี้กับพรุ่งนี้ ถ้าเลื่อนไปดูไกลก็จะเห็นเป็นว่างเปล่า

ทั้งหมดนี้ไม่มีข้อไหนเกี่ยวกับการเล่นวิดีโอ
ซึ่งตัวมันเองก็เป็นเบาะแสที่มีประโยชน์อยู่แล้ว
ช่องที่เล่นได้แต่ไม่มีรายการในผัง กับช่องที่มีรายการในผังแต่เล่นไม่ขึ้น
เป็นคนละปัญหากันและมีคนละสาเหตุกัน อย่างหลังมักเป็น

## ทำไมส่วนที่เป็นหน้าที่ของเครื่องเล่นถึงสำคัญ

ผังรายการคือข้อมูลจำนวนมากที่ต้องถือไว้ให้เรียบร้อย
การแจงไฟล์ XML หลายสิบเมกะไบต์ การทำให้มันทันสมัยอยู่เสมอ
และการวาดตารางที่เลื่อนได้สำหรับช่องหลายร้อยช่อง
โดยที่หน้าตาแอปไม่กลายเป็นของใช้ไม่ได้ คืองานจริง และเป็นงานประเภทที่
[เครื่องเล่นรับผิดชอบจริง ๆ](/th/blog/เครื่องเล่น-iptv-ทำอะไร/)
ต่างจากตัวเนื้อหาที่อยู่ในผังรายการเอง

และมันยังเป็นจุดที่ความเป็นส่วนตัวมีความหมายอยู่เงียบ ๆ
การดึงผังรายการคือการร้องขอไปยัง URL ของผู้ให้บริการของคุณ และไม่ไปที่อื่น
เครื่องเล่นที่รายงานกลับว่าคุณเลื่อนผ่านรายการไหนไปบ้าง
ย่อมกำลังเก็บภาพช่วงค่ำของคุณไว้อย่างละเอียดน่าประหลาด
โดยไม่มีเหตุผลใดเกี่ยวข้องกับการแสดงตารางให้คุณดูเลย
