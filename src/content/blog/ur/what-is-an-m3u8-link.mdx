**M3U8 لنک ایک چھوٹی سی متنی فائل کا پتہ ہے جو M3U فارمیٹ میں لکھی گئی ہو اور
UTF-8 میں محفوظ کی گئی ہو۔** اس کے اندر خود ویڈیو کبھی نہیں ہوتی۔ اس میں جو لکھا
ہے وہی طے کرتا ہے کہ آپ کے ہاتھ میں کیا ہے، اور عملاً یہ دو بہت مختلف چیزوں میں
سے ایک ہوتا ہے:

- **ایک HLS اسٹریم** — ایک چینل یا ایک ویڈیو، جسے چھوٹے ٹکڑوں (سیگمنٹس) کی
  فہرست کی صورت میں بیان کیا گیا ہو اور پلیئر انہیں باری باری لاتا ہو۔ ویب پر
  زیادہ تر جگہوں پر اس ایکسٹینشن کا یہی مطلب ہوتا ہے۔
- **ایک چینل پلے لسٹ** — بہت سے چینلوں کے نام اور ان کی اسٹریمز کے پتے، بالکل
  `.m3u` فائل کی طرح، بس متن UTF-8 میں۔ یہ پہلو
  [M3U اور M3U8 کے فرق](/ur/blog/m3u-اور-m3u8-میں-فرق/) میں تفصیل سے بیان ہوا ہے۔

ایڈریس بار میں دونوں ہوبہو ایک جیسے دکھتے ہیں اور برتاؤ میں ذرا بھی ایک جیسے
نہیں، اس لیے پہلا کام انہیں الگ الگ پہچاننا ہے۔

## کیسے پہچانیں کہ آپ کے پاس کون سا ہے

لنک کو براؤزر میں کھولیں، یا فائل محفوظ کر کے کسی ٹیکسٹ ایڈیٹر میں کھولیں۔ پہلی
چند سطریں ہی سارا راز کھول دیتی ہیں۔

**پلے لسٹ** کسی ڈائریکٹری کی طرح پڑھی جاتی ہے — ایک نام، پھر ایک پتہ، بار بار:

```
#EXTM3U
#EXTINF:-1 tvg-id="one.example" group-title="خبریں",چینل ایک
http://example.com/live/one.m3u8
#EXTINF:-1 tvg-id="two.example" group-title="فلمیں",چینل دو
http://example.com/live/two.m3u8
```

**HLS اسٹریم** کسی ٹائم ٹیبل کی طرح پڑھی جاتی ہے۔ یا تو یہ دستیاب کوالٹیز گنواتی
ہے:

```
#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=2500000,RESOLUTION=1280x720
720p/index.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=6000000,RESOLUTION=1920x1080
1080p/index.m3u8
```

یا خود سیگمنٹس کی فہرست دیتی ہے:

```
#EXTM3U
#EXT-X-TARGETDURATION:6
#EXT-X-MEDIA-SEQUENCE:48213
#EXTINF:6.0,
segment48213.ts
#EXTINF:6.0,
segment48214.ts
```

چینلوں کے نام اور `group-title` نظر آئیں تو یہ پلے لسٹ ہے۔ `#EXT-X-` والی سطریں
نظر آئیں تو یہ اسٹریم ہے۔

## HLS دراصل کیسے چلتا ہے

HLS — HTTP Live Streaming — انٹرنیٹ پر ویڈیو پہنچانے کا سب سے زیادہ استعمال ہونے
والا طریقہ ہے، اور `.m3u8` فائل اس کی فہرستِ مضامین ہے۔

پہلی فائل، یعنی **ماسٹر پلے لسٹ**، ایک ہی پروگرام کو کئی کوالٹیز میں گنواتی ہے، ہر
ایک کے ساتھ یہ کہ اسے کتنی بینڈوڈتھ چاہیے۔ پلیئر ان میں سے ایک چنتا ہے اور اس کی
**میڈیا پلے لسٹ** کھولتا ہے، جس میں اگلے چند سیگمنٹس کے نام ہوتے ہیں، ہر ایک چند
سیکنڈ کا۔ وہ انہیں لاتا ہے، چلاتا ہے، اور اگلے سیگمنٹس جاننے کے لیے میڈیا پلے
لسٹ دوبارہ پڑھتا ہے۔ لائیو چینل کے لیے یہ فہرست مسلسل آگے سرکتی رہتی ہے؛ فلم کے
لیے یہ ایک اختتامی ٹیگ پر ختم ہو جاتی ہے اور پلیئر کو پوری لمبائی معلوم ہوتی ہے۔

کمال کی بات یہ ہے کہ پلیئر سیگمنٹس کے بیچ کوالٹی بدل سکتا ہے۔ کنکشن کمزور پڑے تو
وہ رکنے کے بجائے ہلکے ورژن پر اتر آتا ہے، اور گنجائش بنتے ہی واپس اوپر چلا جاتا
ہے۔ Vidonzo لائیو چینل کو سب سے ہلکے ورژن سے شروع کرتا ہے تاکہ تصویر جلدی سامنے
آئے، پھر خود ہی اوپر کی طرف بڑھتا ہے۔ HLS کا اس کے حریفوں سے موازنہ
[اسٹریمنگ پروٹوکولز کی وضاحت](/ur/blog/اسٹریمنگ-پروٹوکول-کی-وضاحت/) میں
موجود ہے۔

## M3U8 لنک کیسے چلائیں

**اگر یہ پلے لسٹ ہے** تو اس کی جگہ IPTV پلیئر میں ہے، جو اسے چینلوں، کیٹگریوں اور
گائیڈ میں بدل دے گا۔ Vidonzo میں **سروس شامل کریں ← M3U لنک** چنیں اور اسے
**M3U/M3U8 پلے لسٹ URL** والے خانے میں پیسٹ کر دیں۔ اگر پلے لسٹ فائل کی صورت میں
ملی ہے تو **M3U فائل** اسے آپ کے آلے سے لے لیتا ہے۔

**اگر یہ ایک اکیلی اسٹریم ہے** تو آپ کے پاس تین سیدھے راستے ہیں:

1. **VLC۔** *Media → Open Network Stream* چنیں (Mac پر *File → Open Network*)،
   لنک پیسٹ کریں اور چلا دیں۔ VLC ٹھیک اسی کام میں بہترین ہے، اور
   [وہ کہاں ناکافی ہونے لگتا ہے](/ur/blog/کیا-vlc-iptv-پلیئر-ہو-سکتا-ہے/) یہ ایک الگ
   سوال ہے۔
2. **Safari۔** Apple کے براؤزر HLS خود چلا لیتے ہیں، اس لیے براہِ راست `.m3u8`
   لنک اکثر سیدھا ویڈیو میں کھل جاتا ہے۔ دوسرے براؤزرز میں سپورٹ مختلف ہے، اور
   بہت سے اسے صرف ایسے ویب صفحے کے اندر چلاتے ہیں جس میں HLS پلیئر پہلے سے لگا
   ہو۔
3. **اسے پلے لسٹ میں لپیٹ دیں۔** IPTV پلیئر فہرست کی توقع رکھتا ہے، اور ایک
   اندراج والی فہرست بھی فہرست ہی ہے۔ یہ تین سطریں، اپنے نام اور پتے کے ساتھ،
   `stream.m3u` نام کی ایک ٹیکسٹ فائل میں محفوظ کر لیں:

   ```
   #EXTM3U
   #EXTINF:-1,میری اسٹریم
   https://example.com/live/index.m3u8
   ```

   Vidonzo اسے **M3U فائل** کے ذریعے کسی بھی دوسری پلے لسٹ کی طرح پڑھ لیتا ہے،
   اور پھر وہ اسٹریم ایک نام کے ساتھ، باقی سب کچھ کے برابر، آپ کی لائبریری میں
   آ بیٹھتی ہے۔

## M3U8 لنک چلنا کیوں بند کر دیتا ہے

جو لنک کل چلا اور آج نہیں چل رہا، وہ عموماً ان میں سے کسی ایک وجہ سے ہے:

- **اس میں میعاد پہلے سے لکھی تھی۔** بہت سے اسٹریم پتوں میں `?` کے بعد والے حصے
  میں ایک ٹوکن یا دستخط ہوتا ہے — `token=`، `expires=`، `sig=`۔ یہ ایک سیشن یا
  چند گھنٹوں کے لیے کارآمد ہوتے ہیں، پھر سرور 403 کے ساتھ انکار کر دیتا ہے۔ آپ کے
  پلیئر میں کوئی خرابی نہیں؛ بس چابی کی مدت پوری ہو گئی۔
- **یہ صرف وہیں چلتا ہے جہاں سے آیا تھا۔** کچھ سرور دیکھتے ہیں کہ کون سی ایپ یا
  کون سا صفحہ درخواست کر رہا ہے، اور باقی سب کو انکار کر دیتے ہیں۔
- **سیگمنٹس آگے نکل گئے۔** لائیو میڈیا پلے لسٹ میں صرف تازہ ترین چند سیگمنٹس کے
  نام ہوتے ہیں۔ فائل کی صورت میں محفوظ کی گئی نقل چند سیکنڈ میں باسی ہو جاتی ہے۔
- **اسٹریم ختم ہو گئی یا کہیں اور چلی گئی۔** 404 کا مطلب ہے کہ وہ پتہ اب موجود
  نہیں۔

اگر `.m3u8` چینلوں کی پوری پلے لسٹ لوڈ ہو جائے مگر کچھ نہ چلے، تو قصور تقریباً
کبھی ایکسٹینشن کا نہیں ہوتا — اندر لکھے پتوں کا ہوتا ہے۔ اور اگر اسٹریمز شروع ہو
کر چند سیکنڈ میں دم توڑ دیں، تو
[یہ کنکشن کا ٹوٹنا ہے، بفرنگ نہیں](/ur/blog/اسٹریم-چند-سیکنڈ-بعد-رکنا/)،
اور اس کی وجوہات الگ ہیں۔

## خلاصہ

`.m3u8` ایک فہرست ہے، ویڈیو کبھی نہیں۔ اندر چینلوں کے نام ہوں تو یہ پلے لسٹ ہے:
اسے پلیئر کے حوالے کریں۔ `#EXT-X-` والی سطریں ہوں تو یہ ایک HLS اسٹریم ہے: اسے VLC
یا Safari میں کھولیں، یا ایک اندراج والی پلے لسٹ میں لپیٹ دیں۔ اور اگر یہ ایک بار
چلا تھا اور اب نہیں چلتا، تو کہیں اور دیکھنے سے پہلے پتے میں لکھی میعاد دیکھ لیں۔
